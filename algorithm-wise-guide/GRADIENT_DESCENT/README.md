# Gradient Descent

This is my quick note for Gradient Descent.

Gradient descent improves model weights step by step by walking downhill on the error surface.

## Main types
- Batch gradient descent
- Stochastic gradient descent
- Mini-batch gradient descent

## What this topic does
It optimizes parameters by reducing error little by little instead of solving the formula in one shot.

## Simple real-life example
Imagine walking down a foggy hill by checking the slope under your feet and taking repeated downhill steps.
