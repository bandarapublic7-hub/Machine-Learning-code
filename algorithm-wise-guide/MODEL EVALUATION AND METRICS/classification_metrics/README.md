# Classification Metrics

This is my quick note for Classification Metrics.

Classification metrics tell how well the model separates classes, not just how many total guesses were right.

## Main types
- Accuracy
- Precision
- Recall
- F1 score
- ROC AUC

## What this topic does
It measures class prediction quality, especially when class balance or mistake type matters.

## Simple real-life example
In spam detection, missing spam and wrongly blocking a real email are two different problems.
