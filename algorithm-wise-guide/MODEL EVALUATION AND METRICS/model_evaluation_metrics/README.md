# Model Evaluation Metrics

This is my quick note for Model Evaluation Metrics.

Metrics tell you whether a model is truly useful for the business goal, not just mathematically trained.

## Main types
- Regression metrics
- Classification metrics
- Threshold-aware probability metrics

## What this topic does
It measures prediction quality using the right score for the job, like MAE for continuous targets or F1 for imbalanced classes.

## Simple real-life example
For spam detection, accuracy alone can look good while still missing important spam or flagging real emails.
