# Handling Missing Categorical Data

This is my quick note for Handling Missing Categorical Data.

Categorical missing values are usually filled with the most frequent value or a separate Missing label.

## Main types
- Most frequent fill
- Constant category fill

## What this topic does
It fills missing category labels in a simple and readable way.

## Simple real-life example
If city is missing, I can fill it with the most common city or mark it as `Missing`.
