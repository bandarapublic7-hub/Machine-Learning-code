# Handling Mixed Variables

This is my quick note for Handling Mixed Variables.

Mixed variables need cleanup because one column can contain text, numbers, signs, or partly combined values.

## Main types
- String split
- Text and number separation

## What this topic does
It breaks messy mixed-format values into cleaner features.

## Simple real-life example
A value like `3 BHK` or `INR 45000` is easier to model after splitting it into useful parts.
