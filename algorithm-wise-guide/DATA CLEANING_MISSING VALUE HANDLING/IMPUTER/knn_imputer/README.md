# KNN Imputer

This is my quick note for KNN Imputer.

KNN imputer fills a missing value by looking at rows that are most similar.

## Main types
- Distance-based imputation
- Neighbour-based filling

## What this topic does
It estimates missing numbers from nearby rows instead of using one global mean or median.

## Simple real-life example
If one student's science score is missing, you can estimate it from students with similar maths and English scores.
