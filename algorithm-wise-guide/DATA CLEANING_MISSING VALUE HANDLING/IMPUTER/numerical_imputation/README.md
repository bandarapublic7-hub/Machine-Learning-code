# Numerical Imputation

This is my quick note for Numerical Imputation.

For numeric columns, the first simple fixes are usually mean, median, or a chosen constant.

## Main types
- Mean imputation
- Median imputation
- Constant fill

## What this topic does
It fills missing numbers using a simple rule.

## Simple real-life example
If a few ages are missing, I can fill them with median age instead of throwing away the rows.
