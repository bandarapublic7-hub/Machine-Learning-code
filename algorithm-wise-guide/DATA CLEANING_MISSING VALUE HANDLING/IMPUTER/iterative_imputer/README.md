# Iterative Imputer

This is my quick note for Iterative Imputer.

Iterative imputer predicts one missing feature using the other features again and again.

## Main types
- Model-based imputation
- Round-by-round feature prediction

## What this topic does
It fills missing values by learning relationships between columns instead of using one simple fixed rule.

## Simple real-life example
If income is missing, you can estimate it using age, experience, and education, then repeat that idea for other columns.
