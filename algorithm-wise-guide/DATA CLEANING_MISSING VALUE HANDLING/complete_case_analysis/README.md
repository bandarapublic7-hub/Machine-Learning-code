# Complete Case Analysis

This is my quick note for Complete Case Analysis.

Complete case analysis means I keep only the rows where the needed values are present.

## Main types
- Row dropping
- NaN removal

## What this topic does
It removes missing rows when the number of missing values is small enough to afford that loss.

## Simple real-life example
If only 2 out of 500 forms are incomplete, I may just remove those rows and move on.
