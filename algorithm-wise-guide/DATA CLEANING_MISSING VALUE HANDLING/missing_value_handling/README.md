# Missing Value Handling

This is my quick note for Missing Value Handling.

Missing data is normal, and the right fix depends on why the value is missing and how much information the column carries.

## Main types
- Complete case analysis
- Mean and median imputation
- Most frequent and constant imputation
- Missing indicators
- KNN imputation
- Iterative imputation

## What this topic does
It shows both simple and advanced ways to fill, flag, or remove missing values before modeling.

## Simple real-life example
If a restaurant misses a few bills, you might estimate them from similar orders, or you might keep a note saying the amount was missing.
