# Categorical Encoding

This is my quick note for Categorical Encoding.

Machine learning models need numbers, so encoding turns text categories into useful numeric signals.

## Main types
- Ordinal encoding
- One-hot encoding
- Feature name expansion

## What this topic does
It converts labels like low, medium, high or city names into numbers without losing the category meaning.

## Simple real-life example
A delivery app cannot use the word bike directly in a model, so it converts transport type into machine-readable columns.
