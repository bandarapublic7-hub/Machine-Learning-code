# Ordinal Encoding

This is my quick note for Ordinal Encoding.

Use ordinal encoding when the categories have a natural order.

## Main types
- Low-medium-high style labels
- Ranked categories

## What this topic does
It converts ordered labels into numbers while keeping the correct order.

## Simple real-life example
T-shirt size S, M, L has a clear order, so encoding it as ordered values makes sense.
