# One-Hot Encoding

This is my quick note for One-Hot Encoding.

Use one-hot encoding when the category names do not have a natural order.

## Main types
- Nominal category encoding
- Dummy columns

## What this topic does
It creates separate 0 and 1 columns for each category so the model does not treat labels as ranked.

## Simple real-life example
City names like Delhi and Pune are different groups, but one is not greater than the other.
