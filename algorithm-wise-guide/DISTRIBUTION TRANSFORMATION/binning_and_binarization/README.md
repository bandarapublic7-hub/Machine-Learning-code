# Binning and Binarization

This is my quick note for Binning and Binarization.

Sometimes raw numbers are easier to use after turning them into buckets or yes-no flags.

## Main types
- KBinsDiscretizer
- Binarizer

## What this topic does
It turns continuous values into ranges or binary labels.

## Simple real-life example
Age can be turned into teenager, adult, and senior groups. Marks can become pass or fail.
