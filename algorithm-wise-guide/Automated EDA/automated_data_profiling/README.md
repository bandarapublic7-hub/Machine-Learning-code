# Automated Data Profiling

This is my quick note for Automated Data Profiling.

Automated profiling creates a fast summary report when you want a bird's-eye view of the whole dataset.

## Main types
- Schema overview
- Missing value checks
- Correlation hints
- Distribution summaries
- Export to HTML report

## What this topic does
It gives you a ready-made report so you can quickly spot bad columns, missing values, suspicious distributions, and high-cardinality fields.

## Simple real-life example
It is like a doctor doing a full basic checkup before deciding which deeper tests are needed.
