# Date and Time Features

This is my quick note for Date and Time Features.

Date columns become much more useful after I split them into parts like month, weekday, or hour.

## Main types
- Month extraction
- Weekday extraction
- Hour extraction

## What this topic does
It converts timestamps into simpler features that models can use.

## Simple real-life example
An order time can tell me whether the sale happened on a weekend or during office hours.
