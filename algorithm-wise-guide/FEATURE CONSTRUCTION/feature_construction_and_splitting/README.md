# Feature Construction and Splitting

This is my quick note for Feature Construction and Splitting.

Sometimes the best feature is not already present in the raw data, so I make it from the columns I already have.

## Main types
- New feature creation
- Text splitting
- Count features

## What this topic does
It creates better features and breaks combined values into smaller useful parts.

## Simple real-life example
A route like `Delhi -> Goa` is easier to use after splitting it into origin and destination.
