# IQR Outlier Method

This is my quick note for IQR Outlier Method.

IQR uses quartiles, so it works well when the data is not nicely normal.

## Main types
- Q1 and Q3 method
- Boxplot-style outlier rule

## What this topic does
It removes values that fall too far below Q1 or too far above Q3.

## Simple real-life example
This is the same kind of rule often used behind a boxplot.
