# Percentile Outlier Method

This is my quick note for Percentile Outlier Method.

Percentile capping clips extreme values using a chosen lower and upper boundary.

## Main types
- Winsorization style clipping
- Lower and upper percentile cut

## What this topic does
It keeps outliers from stretching the data too much by cutting them to a percentile boundary.

## Simple real-life example
Instead of deleting a very large salary, I can cap it at the 95th percentile.
