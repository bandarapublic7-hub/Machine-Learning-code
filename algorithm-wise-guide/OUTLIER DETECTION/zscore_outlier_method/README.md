# Z-Score Outlier Method

This is my quick note for Z-Score Outlier Method.

Z-score checks how far a value is from the mean using standard deviation.

## Main types
- Mean-based outlier check
- Standard deviation threshold

## What this topic does
It flags values that sit unusually far away from the center.

## Simple real-life example
If most salaries are around 40k to 60k and one row says 300k, z-score will likely flag it.
