# Ridge Regression

This is my quick note for Ridge Regression.

Ridge adds an L2 penalty so very large coefficients are discouraged.

## Main types
- L2 regularization
- Coefficient shrinkage

## What this topic does
It reduces overfitting by spreading weight more smoothly across features.

## Simple real-life example
If a model is giving too much importance to one noisy feature, ridge pulls that weight back.
