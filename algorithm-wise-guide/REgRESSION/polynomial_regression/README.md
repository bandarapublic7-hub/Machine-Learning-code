# Polynomial Regression

This is my quick note for Polynomial Regression.

Polynomial regression is still linear regression underneath, but it first creates curved feature terms.

## Main types
- Quadratic fit
- Higher-degree feature expansion

## What this topic does
It helps when the relationship is curved instead of a straight line.

## Simple real-life example
Study hours and score may rise quickly at first and then level off, so a curve can fit better than one straight line.
