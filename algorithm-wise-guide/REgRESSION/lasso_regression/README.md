# Lasso Regression

This is my quick note for Lasso Regression.

Lasso adds an L1 penalty, which can even push some coefficients fully to zero.

## Main types
- L1 regularization
- Feature selection by shrinkage

## What this topic does
It can simplify the model by keeping only the stronger features.

## Simple real-life example
If a model has many weak signals, lasso can act like a filter and keep the most useful ones.
