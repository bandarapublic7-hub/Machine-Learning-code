# Linear Regression Family

This is my quick note for Linear Regression Family.

Linear regression learns how a target changes when one or more features change.

## Main types
- Simple linear regression
- Multiple linear regression
- Polynomial regression through feature expansion

## What this topic does
It predicts continuous values like price, score, demand, or revenue.

## Simple real-life example
A real-estate model can estimate house price using area, number of rooms, and age of the building.
