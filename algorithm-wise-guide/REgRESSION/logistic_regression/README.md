# Logistic Regression

This is my quick note for Logistic Regression.

Logistic regression predicts classes by estimating probabilities first.

## Main types
- Binary classification
- Multiclass classification
- Probability outputs

## What this topic does
It predicts yes or no outcomes and can also separate more than two classes with softmax-based training.

## Simple real-life example
A bank can use logistic regression to estimate the probability that a customer will default on a loan.
