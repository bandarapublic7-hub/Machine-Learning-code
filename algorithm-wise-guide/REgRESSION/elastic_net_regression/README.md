# Elastic Net Regression

This is my quick note for Elastic Net Regression.

Elastic Net mixes ridge and lasso, so it shrinks coefficients and can still remove some weak ones.

## Main types
- Mixed L1 and L2 regularization

## What this topic does
It gives a balance between stable shrinkage and feature selection.

## Simple real-life example
If ridge feels too soft and lasso feels too strict, elastic net sits in the middle.
