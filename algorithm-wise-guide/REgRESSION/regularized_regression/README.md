# Regularized Regression

This is my quick note for Regularized Regression.

Regularization adds a penalty so the model does not become too flexible and overfit noisy data.

## Main types
- Ridge regression
- Lasso regression
- Elastic Net regression

## What this topic does
It shrinks coefficients, controls model complexity, and helps when many features compete with each other.

## Simple real-life example
If too many people in a meeting keep giving strong opinions, regularization acts like a moderator and asks everyone to stay more balanced.
