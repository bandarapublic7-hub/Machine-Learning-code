# Regression Metrics

This is my quick note for Regression Metrics.

Regression metrics tell how close the predicted numbers are to the real numbers.

## Main types
- MAE
- MSE
- RMSE
- R2 score

## What this topic does
It measures prediction quality for continuous targets.

## Simple real-life example
If a sales forecast misses by 200 units on average, that means something different from missing by 2000 units.
