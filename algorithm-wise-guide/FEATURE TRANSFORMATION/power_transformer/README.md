# Power Transformer

This is my quick note for Power Transformer.

Power transforms help when a numeric column is heavily skewed.

## Main types
- Yeo-Johnson transform
- Skew reduction

## What this topic does
It reshapes a skewed distribution into something closer to a normal spread.

## Simple real-life example
Income data often has a long right tail. A power transform pulls the big values closer so the spread is easier to model.
