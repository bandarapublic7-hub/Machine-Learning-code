# Standardization

This is my quick note for Standardization.

Standardization shifts values around the mean and scales them to a similar spread.

## Main types
- Z-score scaling
- Mean centering
- Unit variance scaling

## What this topic does
It makes numeric features comparable, which helps models like logistic regression, gradient descent, KNN, and SVM.

## Simple real-life example
If salary is in lakhs and age is in years, one column can dominate the model. Standardization brings them onto a fairer scale.
