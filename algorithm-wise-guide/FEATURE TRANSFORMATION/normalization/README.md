# Normalization

This is my quick note for Normalization.

Normalization usually means squeezing values into a smaller fixed range, often 0 to 1.

## Main types
- Min-max scaling
- Range-based scaling

## What this topic does
It keeps values inside a known range, which is useful when features have very different units.

## Simple real-life example
Marks out of 100 and revenue in thousands are hard to compare directly. Normalization puts them on a smaller common range.
