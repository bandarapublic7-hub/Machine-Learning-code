# Scaling and Normalization

This is my quick note for Scaling and Normalization.

Scaling puts features on comparable ranges so one big-number column does not dominate the model.

## Main types
- Standardization
- Min-max scaling
- Vector normalization

## What this topic does
It rescales numeric features so distance-based and gradient-based models learn more fairly and more smoothly.

## Simple real-life example
If one recipe uses grams and another uses kilograms, you convert them to the same unit before comparing ingredients.
