# Feature Engineering

This is my quick note for Feature Engineering.

Good features often matter more than complicated models.

## Main types
- Feature construction
- Feature splitting
- String extraction
- Count-based features

## What this topic does
It creates stronger input columns from raw text, counts, routes, names, and dates.

## Simple real-life example
A birth date by itself may not help much, but age group, school year, and weekend birthday flag can.
