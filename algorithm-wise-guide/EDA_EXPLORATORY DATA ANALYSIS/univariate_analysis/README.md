# Univariate Analysis

This is my quick note for Univariate Analysis.

Univariate analysis means I study one column at a time.

## Main types
- Value counts
- Distribution summary
- Missing value check

## What this topic does
It helps me understand the shape and behavior of one feature before comparing it with others.

## Simple real-life example
If I look only at age, I can find whether most people are young, middle-aged, or older.
