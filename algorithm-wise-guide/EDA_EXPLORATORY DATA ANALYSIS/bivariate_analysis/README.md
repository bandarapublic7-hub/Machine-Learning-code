# Bivariate Analysis

This is my quick note for Bivariate Analysis.

Bivariate analysis means I study how two variables move together.

## Main types
- Crosstab
- Grouped averages
- Correlation

## What this topic does
It helps me check relationships between two features or between one feature and the target.

## Simple real-life example
If I compare study hours and marks together, I can see whether more study time is linked with better marks.
