# Exploratory Data Analysis

This is my quick note for Exploratory Data Analysis.

EDA is the first conversation you have with the dataset before building a model.

## Main types
- Descriptive statistics
- Univariate analysis
- Bivariate analysis
- Correlation checks
- Grouped summaries

## What this topic does
It helps you understand size, spread, missing values, common categories, and relationships between features.

## Simple real-life example
Before opening a new cafe, you would count nearby offices, check foot traffic, and compare weekdays vs weekends. EDA does that for data.
