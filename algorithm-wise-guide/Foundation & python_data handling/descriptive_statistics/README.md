# Descriptive Statistics

This is my quick note for Descriptive Statistics.

Descriptive statistics is the first quick summary I check before doing anything more advanced.

## Main types
- Count
- Mean
- Median
- Standard deviation
- Min and max

## What this topic does
It gives a quick summary of how the data is spread and where the center sits.

## Simple real-life example
Before judging a class result, I would first check average marks, highest marks, and lowest marks.
