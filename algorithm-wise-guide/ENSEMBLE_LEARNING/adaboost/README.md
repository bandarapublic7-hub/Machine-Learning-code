# AdaBoost

This is my quick note for AdaBoost.

AdaBoost builds weak learners one after another and gives more attention to the points that were getting missed.

## Main types
- Sequential boosting
- Weighted learning

## What this topic does
It improves a weak learner by focusing more on hard training examples after each round.

## Simple real-life example
If a teacher notices which questions students keep getting wrong, the teacher can spend more time on those questions next.
