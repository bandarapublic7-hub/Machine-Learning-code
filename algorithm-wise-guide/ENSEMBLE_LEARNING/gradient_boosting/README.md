# Gradient Boosting

This is my quick note for Gradient Boosting.

Gradient boosting builds one small model at a time, and each new one tries to correct the mistakes left by the previous ones.

## Main types
- Sequential boosting
- Residual correction

## What this topic does
It improves performance by learning from the remaining errors stage by stage.

## Simple real-life example
If the first draft of an answer misses some parts, the next draft focuses on exactly those weak sections.
