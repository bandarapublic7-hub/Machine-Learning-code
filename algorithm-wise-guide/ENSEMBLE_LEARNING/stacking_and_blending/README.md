# Stacking and Blending

This is my quick note for Stacking and Blending.

Meta-model methods combine different model families so each one covers the others' weak spots.

## Main types
- Stacking
- Simple probability blending

## What this topic does
It uses multiple base models and then combines or learns from their predictions to create a stronger final model.

## Simple real-life example
A sports commentator, coach, and data analyst may all predict a match differently. A final editor can combine all three views.
