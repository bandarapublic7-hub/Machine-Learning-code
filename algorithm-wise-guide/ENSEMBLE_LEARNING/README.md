# Ensemble Learning

This is my quick note for Ensemble Learning.

Ensembles combine many weak or medium-strength learners so the final prediction is more stable and more accurate.

## Main types
- Random Forest
- AdaBoost
- Gradient Boosting

## What this topic does
It improves performance by aggregating many trees or by sequentially correcting previous mistakes.

## Simple real-life example
Instead of trusting one doctor, you ask a panel of specialists and then combine their opinions.
