# Principal Component Analysis

This is my quick note for Principal Component Analysis.

PCA compresses many numeric columns into a smaller set of summary directions.

## Main types
- Standardization before PCA
- Variance explained
- Two-component projection

## What this topic does
It reduces dimensionality while keeping as much useful variation as possible.

## Simple real-life example
Instead of judging a student by 20 separate quiz scores, PCA can build a few combined study patterns.
