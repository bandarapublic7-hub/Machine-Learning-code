# K-Means Clustering

This is my quick note for K-Means Clustering.

K-means groups similar points together when you do not already have labels.

## Main types
- Sklearn KMeans
- Centroid assignment thinking
- Cluster summary

## What this topic does
It finds cluster centers and assigns each data point to the nearest center.

## Simple real-life example
A school might group students into study circles based on similar attendance and score patterns without knowing the groups in advance.
